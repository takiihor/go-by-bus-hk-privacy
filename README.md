# Take Me by Bus — privacy policy

The public privacy policy for **帶我搭巴士 / Take Me by Bus**, a Hong Kong bus
arrival and journey-planning app.

- **Policy:** <https://takiihor.github.io/take-me-by-bus-privacy/privacy.html>
- **Publisher:** Taki Hor
- **Contact:** takii.hor@gmail.com

## Why this is a separate repository

Both app stores require a privacy policy at a publicly reachable URL. The
application source is developed in a private repository, and GitHub Pages is not
available for private repositories on this account's plan. Rather than make the
application public to host one static page, the policy lives here on its own.

This repository contains only the published pages. It carries no application
source, no release documentation, no data, and no credentials.

## Changing the policy

The policy must describe what the application actually does. Edit `privacy.html`,
update the effective date, and push to `main`; the workflow republishes it.

Material changes should be made together with the corresponding change in the
app, so the published page and the in-app policy do not disagree.
